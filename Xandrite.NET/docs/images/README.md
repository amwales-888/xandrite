# Screenshots for the user manual

`../getting-started.md` uses these images. Take them with the sample models (`Sample Models`, from
`xandrite-sample-models.zip`) as the only library folder, so they match the text. Use PNG, with the window around
1280 × 800 and a light Windows theme. Windows' **Win+Shift+S** (window mode) is a good way to capture just the window.

| File | What to show |
|---|---|
| `01-welcome.png` | The library window on first start, with an empty library: the welcome screen. (Set `XANDRITE_NET_DATA` to an empty folder to get this without losing your own library.) |
| `02-library.png` | **The main picture.** The library window after adding `Sample Models`, with all thumbnails drawn, "All files" selected and medium tiles. Give two or three models a rating and one a custom view first, so the stars and the *custom view* badge show. |
| `03-manage-folders.png` | Preferences ▾ → Manage folders…, with `Sample Models` listed. |
| `04-status-bar.png` | Just the status bar (crop it) while thumbnails are being drawn: "Drawing thumbnails … of …" with the Pause button. Regenerate a few thumbnails (select all, right-click → Regenerate thumbnail) to catch it. |
| `05-browsing.png` | The library window with the folder tree open on `Mechanical`, *Include subfolders* ticked, `gear` in the search box, and *Order by* set to *File size*. |
| `06-context-menu.png` | Right-click on a tile (e.g. `twisted-vase.stl`) with the menu open. |
| `07-find-copies.png` | After right-click → *Find other copies of this model* on `spur-gear-24t.stl`: the two copies (one in `Mechanical`, one in `Mechanical\Spares`). |
| `08-viewer.png` | The viewer with `twisted-vase.stl` (or `torus-knot.stl`), turned to a nice angle. |
| `09-viewer-advanced.png` | The viewer's side panel with **Advanced** expanded (crop to the side panel). |
| `10-preferences.png` | The Preferences ▾ menu open, with the *Thumbnail speed* submenu showing. |
| `11-about.png` | The About Xandrite window. |
